1. Basics of Computers & Hardware Architecture

Fundamental Concepts & Pioneers

  • Four Major Functions (IPOS Cycle): Input → Process → Output → Storage.
  • Charles Babbage: Father of Computers; designed the Analytical Engine (mechanical computer) and Difference Engine.
  • John von Neumann: Developed the Stored Program Architecture (Basic Computer Architecture), unifying program and data memory.
  • Edward Robert: Known as the father of the modern Personal Computer (PC).
  • Ken Thompson & Dennis Ritchie: Co-creators of the UNIX operating system at Bell Labs.
  • First Indian Supercomputer: PARAM 8000, developed by C-DAC (1991). Performance is measured in FLOPS (Floating-Point Operations Per Second), not MIPS.
  • Key Characteristics: High Speed, Accuracy, Diligence (free from tiredness/monotony/lack of focus), Versatility, Automation, NO IQ, NO Feelings.
  • GIGO: Garbage In, Garbage Out (system accuracy reflects input accuracy).

CPU Architecture & Registers

  • CPU Components: ALU (Arithmetic Logic Unit — executes arithmetic & logic), CU (Control Unit — "central nervous system" that directs signal flow), and internal registers.
  • System Buses: Data Bus (bidirectional), Address Bus (unidirectional), Control Bus.
  • Machine Cycle Sequence: Fetch → Decode → Execute → Store. CPU fetches instructions one by one from Main Memory (RAM).
  • Key CPU Registers:
    • PC (Program Counter): Holds address of the next instruction to be executed.
    • MAR (Memory Address Register): Holds address of the active memory location being accessed.
    • MBR / MDR: Holds the data/contents read from or written to memory.
    • Accumulator (AC): Holds intermediate ALU calculation results.
  • Processor Metrics: Clock speed measured in MHz / GHz ($1\text{ MHz} = 10^6\text{ cycles/sec}$). Instruction execution speed measured in MIPS.

Memory Hierarchy & Storage Devices

Memory Pyramid (Top to Bottom):
Registers → Cache (L1, L2, L3) → Main Memory (RAM) → Flash / SSD → Magnetic Disk (HDD) → Optical → Magnetic Tape.
Going UP: Speed increases, Cost/bit increases, Capacity decreases, Access time decreases.
  • Registers: Fastest internal memory inside CPU.
  • Cache Memory: High-speed SRAM situated between CPU and RAM to reduce access time for frequently used data/instructions.
  • RAM (Primary/Volatile): Loses data on power off. SRAM uses flip-flops/latches (faster, no refresh). DRAM uses capacitors and transistors (requires dynamic refresh).
  • ROM (Non-Volatile): Retains firmware/bootloader. Types: PROM, EPROM (erased by UV light), EEPROM (erased electrically). Flash memory is a block-level EEPROM.
  • CMOS Memory: Battery-backed (CR2032) motherboard memory that stores system date, time, and BIOS setup parameters.
  • Secondary / Auxiliary Storage (Persistent):
    • Magnetic Disks: Hard Disk Drive (Winchester disk), Disk Packs, Floppy Disk, Zip disk.
    • Magnetic Tape: Sequential access storage media (used for archiving/backups).
    • Optical Disks: CD-ROM (~700 MB), DVD (~4.7 GB to 8.5 GB), Blu-ray Disc (~25 to 50 GB). "Burning" is the process of writing data to an optical disk.
    • Solid State: SSD, Pen Drive/USB flash drive, Memory Cards.
  • Booting Sequence: Power supply signal → BIOS POST (Power-On Self-Test) → Read CMOS settings → Bootstrap loader loads OS Kernel from secondary storage into RAM.

Input / Output Devices & Display Tech

  • Input Devices:
    • Keyboard: Standard 101/104 keys; function keys F1 to F12.
    • Pointing Devices: Mouse, Trackball, Joystick, Light Pen (optical sensitive input device).
    • Direct Data Entry / Scanning: OMR (Optical Mark Reader — pencil/pen mark detection), OCR (converts printed/scanned text to editable digital text), MICR (Magnetic Ink Character Recognition — used to process bank cheques quickly; reads E-13B font), Barcode Reader, Digitizer/Graphics Tablet, Touchscreen (both input & output).
  • Output Devices:
    • Monitors (VDU - Visual Display Unit): Resolution measured in pixels (smallest addressable visual element on screen). LCD = Liquid Crystal Display; VGA = Video Graphics Array.
    • Printers:
      • Impact Printers: Physical contact with ribbon/paper. Can produce carbon copies. Examples: Drum Printer, Chain Printer, Band Printer, Dot Matrix Printer.
      • Non-Impact Printers: No physical striking. Laser Printer (Page Printer — uses toner and drum), Inkjet Printer (Line/Serial), Thermal Printer.
    • Plotter: Vector output device for CAD drawings/architectural maps.

2. Software Types, Operating Systems & Cyber Security

Software Classifications & Translators

  • System Software: Close to hardware, fast, difficult to design. Includes:
    • Operating System (OS): Intermediary bridge between user/application and hardware. Manages CPU, memory, processes, I/O devices, files. Examples: Windows, Linux, UNIX, macOS, Android, MS-DOS. (Oracle is a DBMS, Spotify is an App).
    • Device Drivers: Translates high-level OS commands into device-specific hardware actions.
    • Language Translators:
      • Assembler: Converts Assembly language to machine code.
      • Compiler: Translates the entire high-level program into machine code in one go.
      • Interpreter: Translates and executes high-level code line-by-line.
  • Utility Software: Maintenance tools. Disk Defragmenter (rearranges fragmented files/contiguous storage to optimize speed), Antivirus, File Compression (ZIP), Disk Clean-up.
  • Firmware: Software permanently flashed onto a hardware ROM/EEPROM chip (e.g., BIOS).
  • Middleware: Enables network communication between distinct applications/services.

OS Core Mechanisms

  • Process: A program currently in a state of execution.
  • Kernel: Core foundational module of an OS handling CPU scheduling, memory management, and file systems.
  • Context Switching: Mechanism of saving the state of the currently executing process and loading the state of a new process into the CPU.
  • Throughput: Total volume of work/processes executed per unit of time.
  • Turnaround Time: Total interval from process submission to completion.
  • Virtual Memory: Technique using secondary storage (hard disk swap space/page file) as an extension of main memory, allowing programs larger than physical RAM to execute.
  • Spooling: Simultaneous Peripheral Operations On-Line (e.g., print spooler queue).
  • Real-Time OS (RTOS): Predictable, rigid time constraints and extremely low latency (used in avionics, robotics, industrial control).

Cyber Security, Threats & IT Act 2000 High-Yields

  • Malware Types:
    • Virus: Self-replicating code that attaches to host files/executables. Boot Sector Virus infects Master Boot Record (MBR). Macro Virus infects MS Office templates (e.g., Melissa Virus).
    • Worm: Standalone malware that self-replicates across networks without needing a host file.
    • Trojan Horse: Disguised as legitimate software to provide backdoor access; does not self-replicate.
    • Spyware / Adware: Covertly monitors user actions and keystrokes (keyloggers).
    • Botnets: Networks of infected computers ("zombies") leveraged to launch DDoS (Distributed Denial of Service) attacks.
  • Attack Vectors:
    • Phishing: Fraudulent communication impersonating trustworthy institutions to steal credentials/PINs.
    • Email Spoofing: Forging sender headers to make emails appear from authentic entities.
    • Spam: Unsolicited commercial bulk email.
    • Bluejacking: Sending unwanted, anonymous messages to Bluetooth devices within proximity.
  • Security Fundamentals:
    • Firewall: Hardware/software boundary barrier filtering packet traffic based on security rules.
    • Digital Signatures: Built on PKI (Public Key Infrastructure) using asymmetric cryptography. Guarantees: Authentication, Data Integrity, and Non-Repudiation (sender cannot deny transmission).
    • Digital Signature Standard (DSS): Formulated by NIST in 1991.
  • Information Technology (IT) Act, 2000 Provisions:
    • Enacted: 9 June 2000; Effective: 17 October 2000. Legal foundation for e-Commerce/e-Governance.
    • Section 17: Appointment of Controller and other certifying officers.
    • Section 27: Display of Certifying Authority license.
    • Section 65: Tampering with computer source documents.
    • Section 66: Computer-related offenses (Hacking / unauthorized access).
    • Section 66E: Violation of bodily privacy.
    • Section 66F: Cyber terrorism.

3. Networks, Data Communications & The Internet

Network Architecture & Topologies

  • Coverage Scale:
    • PAN: Personal Area Network (Bluetooth, up to ~10 meters). Multiple PAN piconets form a Scatternet.
    • LAN: Local Area Network (within a building/room). Uses Ethernet / Wi-Fi.
    • MAN: Metropolitan Area Network (cable TV across a city).
    • WAN: Wide Area Network (spans continents/globe, e.g., the Internet).
    • VPN: Virtual Private Network (extends private tunnel across public network).
  • Network Topologies (Arrangement of Nodes):
    • Star Topology: All nodes connect to a central Hub or Switch. Single cable failure does not break the entire network.
    • Bus: Single backbone backbone cable with terminators at ends.
    • Ring: Token-passing circular loop.
    • Mesh: Dedicated point-to-point links between all nodes; most redundant and robust.
  • Transmission Modes:
    • Simplex: Unidirectional only (Keyboard to CPU, Monitor, TV broadcast).
    • Half-Duplex: Bidirectional, but only one party at a time (Walkie-talkie).
    • Full-Duplex: Simultaneous bidirectional (Telephone line, Modern Ethernet).

Internet Protocols, Addressing & Hardware

  • Transmission Media: Optical Fiber uses total internal reflection to carry light pulses at highest bandwidth.
  • Network Hardware:
    • NIC: Network Interface Card (has hardware MAC address).
    • Switch: Intelligent data-link layer device routing frames to target MAC.
    • Router: Layer 3 device routing packets between different networks.
    • SMPS: Switched-Mode Power Supply (converts AC mains to DC computer voltage).
  • Addressing Architecture:
    • MAC Address: 48-bit physical/hardware address (Hexadecimal: 6 pairs, e.g., 00:1A:2B:3C:4D:5E).
    • IPv4: 32-bit logical address (Dotted decimal: 4 octets, e.g., 192.168.1.1).
    • IPv6: 128-bit logical address (Hexadecimal: 8 blocks separated by colons).
    • DHCP: Automatically assigns dynamic IP addresses to clients on network connection.
  • Key Protocols:
    • HTTP (Port 80) / HTTPS (Port 443): Secure web transmission via SSL/TLS.
    • FTP (Port 20/21): File Transfer Protocol (runs over TCP).
    • SMTP (Port 25): Simple Mail Transfer Protocol (sends/pushes outgoing mail).
    • POP3 (Port 110): Post Office Protocol (downloads/fetches email from server).
    • IMAP (Port 143): Internet Message Access Protocol (syncs mail on server across devices).
    • MIME: Multipurpose Internet Mail Extensions (allows non-ASCII text, audio, video attachments in emails).

Wireless Technologies & Web Concepts

  • ARPANET: First operational packet-switching network (DoD USA, 1969).
  • Father of Email: Ray Tomlinson (1971; introduced the @ symbol).
  • Wi-Fi: Wireless Fidelity (IEEE 802.11 standards). 802.11a supports up to 54 Mbps data rate.
  • WiMAX: Worldwide Interoperability for Microwave Access (IEEE 802.16 standard for broadband wireless).
  • VoLTE: Voice over Long-Term Evolution.
  • GPS (Global Positioning System): Uses Trilateration principle. Needs at least 3 satellites for a 2D surface fix, and 4 satellites for a 3D fix (latitude, longitude, altitude). NAVSTAR was the initial US GPS system.
  • Cookies: Small text files placed by websites on client disk to store sessions and preferences.
  • Ping Utility: Uses ICMP packets to test device connectivity and latency on IP network.

Email Structure & Messaging Terms

  • Email Fields:
    • To: Primary intended recipients.
    • CC (Carbon Copy): Secondary recipients; addresses are visible to everyone.
    • BCC (Blind Carbon Copy): Addresses entered here are hidden/concealed from all other recipients in To, CC, and BCC.
  • Email System Folders:
    • Drafts: Stores composed but unsent messages.
    • Spam/Junk: Filters unsolicited commercial messages.
    • Trash/Bin: Temporarily houses deleted emails before permanent purge.
  • Communication Types:
    • Synchronous: Real-time simultaneous communication (Instant Messaging, Video Conferencing, VoIP).
    • Asynchronous: Time-lagged communication (Email, Discussion Forums, Blogs).

4. Office Productivity Tool: Microsoft Word

Interface, Layout & Formatting Fundamentals

  • Executable Name: winword.exe (run command to launch Word).
  • File Extensions: .doc (pre-2007 binary), .docx (2007+ XML format), .docm (macro-enabled document), .dotx (template).
  • Page Orientation: Portrait (vertical, default) and Landscape (horizontal). Located under Layout / Page Setup tab.
  • Margins & Indents:
    • Margin: Space between text and edge of physical paper.
    • Gutter Margin: Extra space added to the inside/binding edge of document pages.
    • Indentation: Distance between paragraph boundary and text margin (Left, Right, First-line, Hanging). Managed via Ruler.
  • Paragraph Breaks: Pressing Enter inserts a new paragraph. Pressing Shift + Enter inserts a soft line break.
  • Font Style vs Effect:
    • Font Styles: Regular, Bold, Italic, Bold Italic.
    • Font Effects: Strikethrough, Superscript, Subscript, Shadow, Small Caps.
  • Thesaurus (Shift + F7): Tool providing synonyms and antonyms for selected words.

Mail Merge & Advanced Word Features

  • Mail Merge: Feature used to prepare batch personalized letters, envelopes, or mailing labels to multiple recipients.
    • Requires: Main Document (contains fixed boilerplate text) + Data Source (contains recipient fields/records).
    • Merge Fields: Enclosed in chevrons like «Field_Name» (e.g., «name»).
    • Mail Merge Preview shortcut: Alt + Shift + K.
  • Clipboard & Paste Options:
    • Standard copy/cut places content on the Windows/Office Clipboard.
    • Paste Special: Inserts copied clipboard text as unformatted unicode text, picture, or link.
    • Format Painter (Ctrl + Shift + C / Ctrl + Shift + V): Copies only text formatting and applies it to other selections.
  • Navigation & Referencing:
    • Bookmark: Names a specific spot/word in a document for direct navigation.
    • Cross-reference: Links directly to headings, footnotes, figures, tables.

5. Office Productivity Tool: Microsoft Excel

Spreadsheet Structure & Cell Basics

  • Workbook vs Worksheet: A workbook is the Excel file; a worksheet is an individual grid page.
  • Grid Limits (Excel 2007 to 2019/365):
    • Rows: Exactly 1,048,576 rows (numbered 1, 2, 3...).
    • Columns: Exactly 16,384 columns (letters A to XFD).
  • Active Cell & Pointers:
    • Intersection of a row and column forms a Cell.
    • Name Box: Displays address of active selected cell (e.g., D5).
    • Formula Bar: Allows viewing and editing entered values and formulas.
  • Cell Addressing Modes:
    • Relative Reference: Changes during copying (e.g., =A1+B1). Copied down, row adjusts; copied right, column adjusts.
    • Absolute Reference: Locked using dollar ($) signs (e.g., =$A$1 or R1C1 notation R2C2). Does NOT change when copied.
    • Mixed Reference: One dimension locked (e.g., =$A1 locks column, =A$1 locks row).
  • Range Syntax: Contiguous rectangular block denoted with colon (e.g., A1:C9 or B1:E5).

Advanced Data Tools & Lookups

  • Freeze Panes: Keeps header row/column visible while scrolling through large sheets vertically or horizontally.
  • Transpose: Switches data rows to columns and columns to rows.
  • AutoFit: Automatically adjusts column width or row height to fit text contents perfectly.
  • AutoSum Dropdown: Default quick metrics: Sum, Average, Count Numbers, Max, Min (Product is not on default status bar Quick AutoSum).
  • VLOOKUP Syntax: =VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup]). Searches the first column of a range and retrieves matching values horizontally.
  • Conditional Aggregates:
    • SUMIF(range, criteria, [sum_range]): Single condition sum.
    • SUMIFS(sum_range, criteria_range1, criteria1, ...): Multi-condition sum.

6. Office Productivity Tool: Microsoft PowerPoint

Presentations, Views & Master Slides

  • Executable Name: powerpnt.exe.
  • Extensions: .ppt (pre-2007), .pptx (2007+ XML format), .ppsx (direct presentation slide show file).
  • Presentation Viewing Modes:
    • Normal View: Default tri-pane editing workspace.
    • Slide Sorter View: Displays miniature thumbnails of all slides on screen; best view for reordering slides and applying global transitions.
    • Reading View: Fits presentation to current window with playback controls.
    • Slide Show View: Full-screen presentation mode as delivered to the audience.
    • Grayscale View: Previews presentation in black, white, and gray tones without color.
    • Trap: Print Layout View exists in Word, NOT in PowerPoint.
  • Slide Master: Top-level master template that globally controls themes, backgrounds, fonts, and positions across all dependent slides. Handout Master formats printed audience notes.
  • Transitions vs Animations:
    • Transition: Visual motion effect applied to the entire slide when transitioning to the next.
    • Animation Scheme: Motion effects applied to individual elements/objects (text, images, shapes) inside a single slide.

PowerPoint Shortcuts & Multimedia

  • Supported Embedded Audio Formats: .wav and .mid files.
  • New Slide Insertion: Select Home → New Slide or use the standard key combo.

7. National ICT Initiatives & E-Governance Schemes

DigiLocker & National Archives

  • Flagship digital locker initiative under the Digital India campaign.
  • Provides cloud-based electronic storage for Indian citizens to access verified government certificates (Aadhaar, driving licenses, academic marksheets).
  • Issued documents carry equal legal status to physical originals under the IT Act 2000.
  • NDLI: National Digital Library of India (IIT Kharagpur/Ministry of Education initiative).

UMANG & NeGP

  • NeGP: National e-Governance Plan, formally approved in 2006.
  • UMANG: Unified Mobile Application for New-Age Governance.
    • Launched by MeitY (Ministry of Electronics and Information Technology) and NeGD.
    • Serves as a single unified portal/app accessing central and state services (EPFO, Passport, Gas Cylinder booking, PAN).

E-Commerce & Digital Governance

  • E-Commerce Models: B2C (Business to Consumer, e.g., Amazon, Flipkart), B2B (Business to Business), C2C (Consumer to Consumer, e.g., OLX).
  • NPCI Services: Unified Payments Interface (UPI), RuPay, IMPS, National Financial Switch (NFS). (NPS is governed by PFRDA, not NPCI).
  • UIDAI: Established in 2016 as a statutory authority under the Aadhaar Act (originally set up in 2009).
